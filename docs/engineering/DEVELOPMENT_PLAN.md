# HALAL-INVEST: Engineering Development Plan

## Phase Structure
- **Phase 1:** Repository Inspection & Baseline Documentation (Completed).
- **Phase 2:** ADR formulation and Architecture Documentation (Completed).
- **Phase 3:** Domain Engine Implementation (Financial Calculator, AAOIFI Shariah Screener, Valuation Engine, Risk Engine, Red-Team Engine, Safety Gate).
- **Phase 4:** Data Layer & PostgreSQL Schemas with In-Memory Transactional Adapter.
- **Phase 5:** API Gateway & FYERS Broker Adapter (Server-side isolation, zero auto-trade).
- **Phase 6:** Frontend UI Implementation (Dashboard, Company Research, Screener, Portfolio, Watchlist, Markets, Events, Settings).
- **Phase 7:** Automated Unit, Integration, and Safety Tests.
- **Phase 8:** Build Compilation & Strict Verification.
